### Software Engineer · Geospatial Technology · AI & Automation

I’m a software engineer based in **Kenya**, interested in building practical systems that connect **software, geospatial data, artificial intelligence, and automation**.

My path into software started with **land surveying and cartography**, followed by experience in technology operations and data workflows. That background influences how I build: I like understanding the real-world problem first, then turning it into something useful, reliable, and easy to work with.

> **Surveying & Cartography → Operations & Data → Software Engineering → Geospatial + AI**
